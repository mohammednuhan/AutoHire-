# AutoHire

Open-source, self-hosted autonomous job application agent for Indian tech students and freshers.

## One-Command Setup

```bash
git clone https://github.com/yourname/autohire
cd autohire
cp .env.example .env
# Edit .env: add your GEMINI_API_KEY and TELEGRAM_BOT_TOKEN
docker compose up
```

Then open http://localhost:3000
